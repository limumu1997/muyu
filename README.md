# 赛博木鱼 · 功德即工资

输入薪资和班表，算出你每一秒值多少钱。**不敲的时候功德一直叠加，敲一下全部收走**——攒得越久，一敲越响。

纯原生 HTML/CSS/JS，零依赖、零构建，双击 `index.html` 就能用，也可以直接扔任意静态托管。

## 玩法

- 只在**你设定的上班时段内**累计（午休、非工作日、下班后都不走表）
- 未结功德封顶 **1 小时工作量**——摸太久了会提示你赶紧敲，超出的时间白流
- 敲击结算进累计功德，记录敲击次数和最高单击

## 计算方式

```
每秒收入 = 月薪 ÷ (每月计薪天数 × 每日计薪秒数)
每日计薪秒数 = 下班 − 上班 − 落在班内的午休
未结功德 = 每秒收入 × min(距上次敲击的计薪秒数, 3600)
```

支持跨夜班（如 22:00–06:00，按开班日判断工作日）。

## 画面与声音

全部现场生成，**没有一个图片或音频文件**：

- **月夜远山**：CSS 渐变 + SVG 山形 + 缓慢漂移的雾与浮尘。雾用径向渐变而不是 `filter:blur`，省 GPU
- **立体感**：没上 three.js。木鱼有极慢的呼吸浮动、受击时沿 X 轴翻转下沉，木槌用 `rotateX` 沿自身长轴朝观察者倾斜，柄画成近端粗远端细
- **敲击音**：模态合成——几个不成谐波列的衰减正弦（比例 1 : 1.94 : 3.31 : 5.12，非整数比才是木头的闷，整数比会变成钟）+ 木质颗粒噪声 + 高频接触瞬态
- **禅意背景音**（可关）：低频 drone 打底 + D 宫五声音阶随机长音 + 偶尔一记磬，全部过一个程序生成的混响。首次点击后才启动（浏览器不允许无交互自动播放），切到后台自动停

想调音色：`app.js` 顶部的 `F0` 是敲击音高（大木鱼降到 ~380，小木鱼 ~700），`SCALE` 是背景音的音阶。

## 用法

```bash
# 本地起个静态服务（PWA / Service Worker 需要 http，file:// 下不生效）
python3 -m http.server 8765
# 打开 http://127.0.0.1:8765
```

首次打开自动弹设置面板，填月薪即可开始。空格 / 回车也能敲。

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构，木鱼与木槌均为内联 SVG |
| `style.css` | 全部样式与动画 |
| `app.js` | 班表计算、结算逻辑、Web Audio 合成木鱼音与背景音 |
| `sw.js` / `manifest.webmanifest` / `icon.svg` | PWA，可装到手机桌面、离线可用 |

## 数据

薪资配置和功德记录都存在浏览器 `localStorage`（`muyu.cfg` / `muyu.state`），不上传任何地方。设置面板里的「清空功德」可重置记录。
